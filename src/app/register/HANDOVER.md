# Registration Page Handover

Canonical self-service registration is a single email/password form with an
optional display name. Access codes, invitations, Google registration, direct
public-table writes, and automatic sign-in are intentionally absent. Success
is an inline check-email state with one return to sign in.

Standalone desktop/mobile browser acceptance confirms local rule/mismatch
validation, disabled loading state, one intercepted 202 request, and the single
check-email recovery action.
