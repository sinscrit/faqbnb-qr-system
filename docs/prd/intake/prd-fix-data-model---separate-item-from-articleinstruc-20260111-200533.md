## Overview

The application confuses the relationship between Items, Articles, and QR codes. Correct Data Model: Item = A physical thing that gets ONE QR code (e.g., Fridge, Oven, Steamer). Article = Instructions/content about an item, multiple per item (e.g., "How to Clean", "How to Turn Off"). Purpose = Article Title (same thing). QR Code = ONE per Item (not per article) - Scan "Fridge" to see all articles.

## Current State

The UI conflates Item and Article. Shows "Article Title" as "How to Clean - Steamer" and says this will appear on the QR code label.

## Requirements

### Required Changes

- Item Name should be just the item (e.g., "Steamer") — NOT "How to Clean - Steamer"
- Article Title = Purpose (e.g., "How to Clean")
- QR Code label shows Item Name only (e.g., "Steamer")
- When user scans QR for "Steamer," they see list of all articles
