REQUEST REQ-2: Fix Data Model - Separate Item
from Article/Instructions
Screen: Step 8 - Item Details
Priority: CRITICAL
Current State
The UI conflates Item and Article. Shows "Article Title" as "How to Clean - Steamer" and says
this will appear on the QR code label.
Problem - Data Model Misunderstanding
The application confuses the relationship between Items, Articles, and QR codes.
Correct Data Model
Concept Description Example
Item A physical thing. Gets ONE QR code. Fridge, Oven, Steamer
Article Instructions/content about an item. Multiple per item"H.ow to Clean", "How to Turn Off"

Purpose = Article Title (same thing) "How to Clean"
QR Code ONE per Item (not per article) Scan "Fridge" fi see all articles
Required Changes
(cid:127) Item Name should be just the item (e.g., "Steamer") — NOT "How to Clean - Steamer"
(cid:127) Article Title = Purpose (e.g., "How to Clean")
(cid:127) QR Code label shows Item Name only (e.g., "Steamer")
(cid:127) When user scans QR for "Steamer," they see list of all articles
