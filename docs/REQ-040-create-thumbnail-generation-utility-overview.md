## Summary

This document outlines the implementation plan for creating a thumbnail generation utility (`thumbnailGenerator.ts`) that provides canvas-based thumbnail creation from captured photos and video frames. This utility is a foundational component for the ItemCapture workflow, enabling efficient preview displays in gallery views.

## Requirements Analysis

### From REQ-040 Acceptance Criteria

| Criterion | Implementation Approach |
|-----------|------------------------|
| 200x200 pixel thumbnails from photos | Canvas-based resize with aspect ratio preservation |
| Representative frame from videos | Extract frame at 0.5s mark using video element + canvas |

## Technical Design

### API Specification

```typescript
// src/components/ItemCapture/utils/thumbnailGenerator.ts

/**
 * Configuration options for thumbnail generation
 */
export interface ThumbnailOptions {
  /** Target width in pixels (default: 200) */
  width?: number;
  /** Target height in pixels (default: 200) */
  height?: number;
  /** JPEG quality 0-1 (default: 0.8) */
  quality?: number;
  /** Output format (default: 'image/jpeg') */
  format?: 'image/jpeg' | 'image/png' | 'image/webp';
  /** Fit strategy: 'cover' crops to fill, 'contain' fits within bounds */
  fit?: 'cover' | 'contain';
}

/**
 * Generate a thumbnail from an image file or blob
 * @param imageSource - Image File, Blob, or object URL string
 * @param options - Thumbnail configuration
 * @returns Promise resolving to thumbnail Blob, or null on failure
 */
export async function generateImageThumbnail(
  imageSource: File | Blob | string,
  options?: ThumbnailOptions
): Promise<Blob | null>;

/**
 * Generate a thumbnail from a video file, blob, or element
 * @param videoSource - Video File, Blob, object URL, or HTMLVideoElement
 * @param options - Thumbnail configuration
 * @param seekTime - Time in seconds to extract frame (default: 0.5)
 * @returns Promise resolving to thumbnail Blob, or null on failure
 */
export async function generateVideoThumbnail(
  videoSource: File | Blob | string | HTMLVideoElement,
  options?: ThumbnailOptions,
  seekTime?: number
): Promise<Blob | null>;

/**
 * Generate thumbnail from any supported media type
 * Automatically detects type and routes to appropriate generator
 * @param source - Media source (File, Blob, or URL string)
 * @param options - Thumbnail configuration
 * @returns Promise resolving to thumbnail Blob, or null on failure
 */
export async function generateThumbnail(
  source: File | Blob | string,
  options?: ThumbnailOptions
): Promise<Blob | null>;
```

### Algorithm Details

#### Image Thumbnail Generation

```
1. Load image source into HTMLImageElement
2. Wait for 'load' event (with timeout)
3. Calculate scaling and crop region based on fit strategy
4. Create offscreen canvas (200x200)
5. Draw scaled/cropped image to canvas
6. Convert canvas to Blob (JPEG, quality 0.8)
7. Clean up resources (revoke object URLs if created)
```

#### Video Thumbnail Generation

```
1. Create or use HTMLVideoElement
2. Set video source (object URL if File/Blob)
3. Wait for 'loadeddata' event
4. Seek to target time (default: 0.5s)
5. Wait for 'seeked' event
6. Draw current video frame to canvas
7. Convert canvas to Blob
8. Clean up (revoke object URLs, pause video)
```

#### Fit Strategy: Cover vs Contain

**Cover (default):** Scales image to completely fill the thumbnail area, cropping edges if necessary. Best for consistent grid layouts.

```
Source: 1920x1080 (16:9)
Target: 200x200 (1:1)
Scale: max(200/1920, 200/1080) = 0.185
Scaled: 355x200
Crop: Center crop to 200x200
```

**Contain:** Scales image to fit entirely within thumbnail, may have letterboxing. Best when full content visibility matters.

```
Source: 1920x1080 (16:9)
Target: 200x200 (1:1)
Scale: min(200/1920, 200/1080) = 0.104
Scaled: 200x112
Position: Center with transparent/white padding
```

export async function generatePDFThumbnail(file: File): Promise<Blob | null> {
  try {
    // ... canvas operations

    return null;
  }

- Return `null` on failure instead of throwing
- Use JSDoc comments for function documentation
- Keep utilities pure (no side effects beyond the operation)

- Lazy loading via dynamic imports: `dynamic(() => import('./path'), { ssr: false })`

## Risk Assessment

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| HEIC format not supported by canvas | Medium | Low | Detect HEIC and skip thumbnail; parent can convert |
| Large images cause memory pressure | Medium | Medium | Use createImageBitmap() for large files if available |
| Video seek fails on some formats | Low | Medium | Fallback to first frame (time 0) |
| iOS Safari canvas quirks | Low | Low | Test on iOS; use standard canvas APIs |
| Performance > 500ms on slow devices | Medium | Medium | Optimize canvas operations; consider Web Workers for V2 |

## Success Criteria

1. **Functional:**
   - Generates 200x200 thumbnails from JPEG, PNG, WebP images
   - Extracts frame at 0.5s from MP4, WebM videos
   - Returns Blob objects suitable for object URL display
   - Handles errors gracefully (returns null, logs error)

2. **Performance:**
   - Completes in < 500ms for typical mobile captures (3-5 MB)
   - No memory leaks (object URLs revoked)
   - Does not block main thread for extended periods

3. **Quality:**
   - Thumbnails display clearly at 200x200
   - No visible distortion or stretching
   - Consistent appearance across different source aspect ratios

4. **Integration:**
   - Works with existing `pdfThumbnailGenerator.ts` pattern
   - Compatible with `MediaItem.thumbnail` Blob storage
   - Can be dynamically imported for code splitting
